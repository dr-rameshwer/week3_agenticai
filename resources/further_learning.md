## 1. Seminal Academic Research Papers
1. **Attention Is All You Need** (Vaswani et al., 2017)
   * *Topic*: The Transformer architecture, self-attention mechanisms, and sequence-to-sequence modeling.
   * *Link*: [arXiv:1706.03762](https://arxiv.org/abs/1706.03762)
2. **Language Models are Few-Shot Learners** (Brown et al., 2020 - GPT-3)
   * *Topic*: In-context learning, few-shot prompting, and scaling laws.
   * *Link*: [arXiv:2005.14165](https://arxiv.org/abs/2005.14165)
3. **Chain-of-Thought Prompting Elicits Reasoning in Large Language Models** (Wei et al., 2022)
   * *Topic*: Step-by-step problem decomposition and observable reasoning.
   * *Link*: [arXiv:2201.11903](https://arxiv.org/abs/2201.11903)
4. **Toolformer: Language Models Can Teach Themselves to Use Tools** (Schick et al., 2023)
   * *Topic*: Function calling and API invocation mechanics by language models.
   * *Link*: [arXiv:2302.04761](https://arxiv.org/abs/2302.04761)

## 3. Next Steps in Agentic AI Engineering
After mastering Week 3, students are encouraged to explore:
* **Retrieval-Augmented Generation (RAG)**: Chunking, dense vector embeddings, cosine similarity, and vector databases (LanceDB, ChromaDB, Pinecone).
* **Multi-Agent Orchestration**: Multi-step autonomous workflows, state machines, and message passing.
* **Model Evaluation & Observability**: Tracing API latency, logging token consumption, and automated benchmark scoring.
