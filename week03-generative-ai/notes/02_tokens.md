## 2. Why Are We Learning This?
In commercial AI software engineering, **tokens are money and latency**. Every word sent and every word generated incurs a monetary cost and adds generation time. Engineering applications without monitoring token usage will lead to budget overruns and slow user experiences.

---

## 3. Concept in Simple Words
Computers do not read words or letters directly; they process numbers. A **Tokenizer** splits text into numeric chunks called **Tokens**. On average in English:
$$\mathbf{100 \text{ tokens}} \approx \mathbf{75 \text{ words}} \quad \text{or} \quad \mathbf{1 \text{ token}} \approx \mathbf{4 \text{ characters}}$$

---

## 4. Real-World Analogy
Think of sending an old-fashioned telegram or an SMS where you are charged per character block:
* If your prompt is long and wordy, you pay a higher **Input Fee**.
* If the reply is an essay, you pay a higher **Output Fee**.
* If you exceed the maximum page limit (**Context Window**), the telegraph office rejects your message.

---

## 5. Technical Explanation
When text is submitted to `client.models.generate_content(...)`:
1. The text is passed through a Byte-Pair Encoding (BPE) tokenizer to convert characters into an array of token IDs $[t_1, t_2, \dots, t_N]$.
2. The number of input token IDs is reported in `usage_metadata.prompt_token_count`.
3. The model generates output token by token until it produces a stop token (e.g., `<EOS>`) or hits `max_output_tokens`.
4. The generated token count is reported in `usage_metadata.candidates_token_count`.
5. The sum is reported in `usage_metadata.total_token_count`.

---

## 6. Important Terminology
* **Token**: Sub-word numerical representation unit (e.g., `"learning"` $\to `["learn", "ing"]`$).
* **Prompt Tokens ($N_{in}$)**: Number of tokens in user input + system prompt.
* **Completion / Candidate Tokens ($N_{out}$)**: Number of tokens generated by the model.
* **Total Tokens**: $N_{in} + N_{out}$.
* **Context Window**: Maximum tokens a model can hold in memory at once (e.g., 1M+ tokens for Gemini 2.5 Flash).
* **Token Budget**: Maximum allowable tokens allocated to a specific API request.

---

## 7. Python Syntax & Concepts Encountered
* `response.usage_metadata`: The object containing token count integers.
* `getattr(obj, 'attr_name', default)`: Safe attribute access in Python.
* Formatted string literals (f-strings) with numeric formatting: `f"{cost:.6f}"`.

## 8. Smallest Working Example (`02_token_inspector.py`)

```python
import os
from dotenv import load_dotenv
from google import genai

load_dotenv()
client = genai.Client(api_key=os.getenv("GEMINI_API_KEY"))

prompt = "List the three primary laws of robotics formulated by Isaac Asimov."

response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents=prompt
)

print("--- Generated Text ---")
print(response.text)

# Inspect token usage metadata
usage = response.usage_metadata
print("\n--- Token Usage Metrics ---")
print(f"Prompt Tokens (Input):     {usage.prompt_token_count}")
print(f"Candidates Tokens (Output): {usage.candidates_token_count}")
print(f"Total Tokens:              {usage.total_token_count}")
```

## 13. Common Mistakes
1. Assuming 1 word equals 1 token (words with punctuation, numbers, or non-English characters often use 2–3 tokens per word).
2. Forgetting that system instructions and few-shot examples count towards **prompt tokens** on *every single request*.

## 18. Viva Questions
1. *Why do output tokens cost more than input tokens on most cloud platforms?*  
   **Answer**: Input tokens can be processed in parallel across attention matrices in a single forward pass, whereas output tokens must be generated autoregressively one token at a time.
2. *What is a context window?*  
   **Answer**: The total maximum capacity of tokens (input + output) an LLM can hold in active attention.

---

## 19. Interview Questions
1. *How would you reduce token costs in a multi-turn chat application with 50 turns?*  
   **Answer**: Use sliding-window context truncation, conversation summarization, semantic vector caching, and compact system prompts.
