## Core Viva Questions & Model Answers

### 1. What is an API key and why should it never be hardcoded into Python source files?
* **Answer**: An API key is a secret token used to authenticate requests to a remote service and bill usage to an account. Hardcoding it into source files exposes it to accidental commits in version control systems (like GitHub), which can lead to quota theft, data exposure, or financial liability. Best practice is to store it in a `.env` file and read it via `os.getenv()`.

---

### 2. What is the difference between `prompt_token_count`, `candidates_token_count`, and `total_token_count`?
* **Answer**:
  * `prompt_token_count` (Input tokens): The number of tokens contained in the prompt, system instructions, and few-shot examples sent to the model.
  * `candidates_token_count` (Output/Completion tokens): The number of tokens generated by the model in its response.
  * `total_token_count`: The sum of prompt tokens and completion tokens. Both are billed at different rates by cloud providers.

---

### 3. If temperature is set to `0.0`, is the LLM output 100% guaranteed to be identical across different days?
* **Answer**: Setting temperature to `0.0` maximizes determinism (greedy argmax decoding). However, across different days or infrastructure updates, providers may update underlying GPU kernels, mixture-of-experts routing, floating-point precision, or model minor versions. Thus, it is practically deterministic for identical sessions, but long-term reproducibility across model versions requires version pinning.

---

### 4. What is a System Instruction and how does it differ from a User Prompt?
* **Answer**: 
  * A **System Instruction** sets the overarching context, persona, guardrails, response format, and behavioral constraints of the model across the entire session.
  * A **User Prompt** provides the specific task, question, or payload for the immediate interaction. System instructions take higher precedence in steering persona and safety constraints.

---

### 5. Why is Few-Shot prompting better than Zero-Shot for structured classification tasks?
* **Answer**: Large language models learn patterns in-context. By showing 2–4 concrete input-output examples, the model understands the exact vocabulary, syntax, delimiter format, and boundary conditions without ambiguous natural language instructions.

---

### 6. What does `BaseModel` do in Pydantic?
* **Answer**: `BaseModel` is the fundamental class in Pydantic from which user-defined schemas inherit. It provides automated type checking, coercion, attribute initialization (without writing `def __init__`), validation via type hints, and serialization to Python dictionaries (`model_dump()`) or JSON (`model_dump_json()`).

---

### 7. What happens when invalid data is passed to a Pydantic model?
* **Answer**: Pydantic raises a `ValidationError` exception containing an error collection detailing every failed field, the input value that caused the error, and the validation rule that failed (e.g., `value_error.missing` or `type_error.integer`).

---

### 8. Explain how a Python function is converted into an LLM Tool.
* **Answer**: The Python function's name, type annotations, and docstring are inspected and translated into an OpenAPI/JSON Schema tool definition. The LLM reads this definition to know what the tool does, what arguments it requires, and when it is appropriate to call it.

---

### 9. What is the role of Uvicorn in running a FastAPI application?
* **Answer**: FastAPI is an application framework that implements the ASGI (Asynchronous Server Gateway Interface) specification. It does not run an HTTP server on its own. Uvicorn is a lightning-fast ASGI web server implementation that listens for incoming TCP/HTTP connections and passes requests to the FastAPI application.

---

### 10. How does FastAPI automatically generate interactive API documentation?
* **Answer**: FastAPI reads the Python type hints and Pydantic schemas declared on path operations (`@app.get`, `@app.post`) and compiles them into a standard OpenAPI JSON specification. Uvicorn/FastAPI then serves this specification via Swagger UI at the `/docs` endpoint.
